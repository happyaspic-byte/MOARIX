# 제품 로드맵

## 현재 운영 코어

- 인증·역할·회사 격리
- 기준정보
- 5종 업무 문서와 승인 상태
- 재고 잔량·입출고·조정 원장
- 고객 자산과 SLA 업무 큐·상세·활동·첨부 참조를 갖춘 서비스 케이스
- 대시보드·표준 보고서·감사 로그
- 고객 사업장과 고객 360° 상세
- Stratus 자산 360°, Node/CMA/BMC/A-Link/VM 토폴로지와 라이선스
- 고객계약·벤더 백계약 분리, 개정 이력과 D-90·60·30·0 위험 큐
- 정기점검 불변 체크리스트와 서비스 케이스 Task Watch List·상호 링크
- 운행일지 비용 자동 계산, 버전 기반 수정과 작성자/승인자 분리
- AI용 `moarix`/`mx` CLI, 최소 권한 API 토큰, capability JSON Schema와 멱등 명령 API
- 실제 PostgreSQL 제한 역할과 RLS 보안 게이트

## P1: 거래 문서 완성도

- 다중 품목 행 편집, 행 순서와 일괄 할인
- 견적 → 수주 → 출고 → 매출청구, 발주 → 입고 → 매입청구 변환
- PDF 인쇄 양식과 메일 발송
- 승인 한도·다단계 승인·반려 사유
- 입금·지급·미수/미지급 배부와 에이징

## P1: 운영·관리

- 사용자 초대, 비밀번호 초기화, 역할 변경 및 API 토큰 수명주기 UI
- 세션 목록과 강제 로그아웃
- 재고 이동·예약·역분개 UI와 실사 문서
- CSV 가져오기·내보내기
- 검색, 기간 필터, 페이지네이션
- 담당자 재배정, 심각도 변경 이력과 외부 이벤트 멱등 가져오기
- S3 호환 비공개 객체 저장소의 서명 업로드·SHA-256·악성코드 검사·보유 정책
- 점검 결과 Excel/PDF 내보내기와 고객 확인
- 자산·계약 CSV/XLSX 가져오기, 열 매핑과 오류 행 검증

## P2: 외부 연동

- 전자세금계산서 공급자 연동
- 은행 거래·카드·결제대행 연동
- 이메일·알림 채널
- 회계 프로그램 또는 표준 분개 내보내기
- SSO/OIDC와 SCIM
- ServiceNow 등 지원 포털 API/Webhook 동기화와 실패 재처리·대사

## P2: 고급 운영

- 사용자 정의 필드와 문서 템플릿
- 고객 포털과 서비스 SLA 자동화
- 예산·프로젝트 손익
- 다통화 환율과 외화평가
- 데이터 웨어하우스·BI 커넥터

각 항목은 실제 사용 조직의 회계·세무·승인 정책을 확인한 뒤 구현합니다. 외부 서비스 기능은 공급자 계약, 샌드박스, 장애·재시도·대사 절차까지 완료해야 운영 완료로 간주합니다.
